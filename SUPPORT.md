# Getting help

- **How do I...?** Look in the [README](README.md) first, then ask in
  [Discussions](https://github.com/LeeSwallow/stickypane/discussions), Q&A.
  Others will have the same question; the answer stays findable there.
- **It does not work.** Run `stickypane version` and `stickypane env`, then
  open a [bug report](https://github.com/LeeSwallow/stickypane/issues/new?template=bug.yml)
  with their output and the screen.
- **My agent does not use the board well.** That is design feedback, the
  most useful kind of issue right now:
  [design feedback](https://github.com/LeeSwallow/stickypane/issues/new?template=design_feedback.yml).
- **A security problem.** Privately, as [SECURITY.md](SECURITY.md) says.

stickypane has one maintainer who answers within a week, usually sooner.
There is no paid support.

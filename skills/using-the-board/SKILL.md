# Using the board

## Loading instructions

1. Read `references/rules.md` first: what the board is and what not to
   touch.
2. Read `references/flow.md` to choose how to put something there: show a
   file, run a one-line command, or write a file.
3. Read `references/formats.md` only when writing a file with a shape of its
   own (board, checklist, chart, form, diagram).
4. Follow `${CLAUDE_PLUGIN_ROOT}/rules/writing-notes.md` when writing text
   the user will read on the board.

This skill puts things on the board and reports the board's one-line
answers. It does not wait for the user: that is `asking-the-user`.

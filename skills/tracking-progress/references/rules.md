# Rules

- One note per task the user follows. A second checklist for the same task
  is noise; update the one that exists.
- Change notes with the one-line commands, never by rewriting the file:
  the user may have ticked or added items from the board, and a rewrite
  would drop them.
- A step is a line a reader understands without the chat: "move the
  function", not "step 2".
- One line per log entry; `--time` when the order of events matters.
- Leave the finished note where it is. It is the record. Delete it only
  when the user asks.
- Keep the board honest: tick an item when it is done, not when you start
  it.

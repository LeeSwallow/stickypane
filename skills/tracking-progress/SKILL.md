# Tracking progress on the board

## Loading instructions

1. Read `references/rules.md`: one note per task, updated, never
   rewritten.
2. Read `references/flow.md` for the three moments: start, while working,
   finish.
3. When the work needs the user's decision, use `asking-the-user`.

This skill only keeps the board current. It does not decide what the work
is.

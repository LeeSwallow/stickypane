---
description: Every note on the stickypane board in a line, or the ones that match
allowed-tools: Bash(stickypane:*)
---

Run `stickypane index` and show the user the notes it lists, grouped by tab
as it prints them. With an argument, show only the lines that match
`$ARGUMENTS`, and read a note with `stickypane cat <name>` only when the
user asks about it.

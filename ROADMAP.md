# Roadmap

Where stickypane is going, in three columns. The design questions that
decide the order are open for discussion: see the pinned post in
[Discussions](https://github.com/LeeSwallow/stickypane/discussions).

## Now (before v0.1.0)

- Use it daily and fix what gets in the way.
- Settle the file names and the command names; after v0.1.0 they stay.
- Translations of the user interface (hints, messages, help), starting
  with Korean; the agent guide stays in English.

## Next

- A status line: what the agent is doing, in one line, always visible.
- Tables and trees as note shapes.
- Buttons that send a message to the agent (`ask:`), not only run a script.
- Resizing panes in four directions, by key and by mouse.
- Usage charts fed by the agent's own session logs, in the way ccusage
  reads them.

## Later

- A board shared by several agents at once.
- Windows.

## Open design questions

- One board, or a folder per dashboard?
- Should what is open be shared through `sticky.json` or kept per user?
- Which note shapes earn their place, and which do agents never use?

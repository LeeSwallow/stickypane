# History

The plans and design specs the board was built from, each dated and
written before or while its change was made. They record the code as it
was at the time and are not kept current: a name, a path or a rule here
may have changed since. What the code is now is in
[architecture.md](../architecture.md) and the tests; why a design was
chosen, when it still matters, is in the
[desktop app's decision records](../desktop/adr/).

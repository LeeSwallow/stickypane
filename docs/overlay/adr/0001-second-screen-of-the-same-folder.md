# ADR-0001. overlay는 같은 폴더의 두 번째 화면이다

| 항목 | 값 |
|---|---|
| 상태 | Proposed |
| 날짜 | 2026-10-28 |
| 관련 요구 | R-04, R-07 |

## 맥락

stickypane은 터미널에 board를 그린다. 터미널은 Markdown 일부, ASCII 다이어그램만 그릴 수 있고 여러 에이전트의 움직임을 보여 주기 어렵다. 사용자는 같은 유스케이스를 유지한 채 시각화 레이어를 더하길 원한다(R-04).

## 결정

overlay는 `.sticky/`를 읽고 `doc.Op`로 쓰는 **두 번째 화면**이다. 자기 데이터 모델이 없다. overlay에서 할 수 있는 모든 일은 터미널이나 CLI로도 할 수 있다. 에이전트는 overlay가 있는지 모른다.

## 결과

- VISION의 여섯 원칙이 그대로 유지된다.
- overlay만의 기능이 생기면 이 결정을 어긴 것이다(반목표 X1).
- 터미널 board와 overlay가 같은 노트를 다르게 보여 주면 버그다.

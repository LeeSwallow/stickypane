## 3.1 디자인 원칙

| # | 원칙 | 화면에서의 모습 |
|---|---|---|
| D1 | **붙이고 바로 쓴다** | "+ 끄적이기" 한 번에 노란 메모지가 붙고 바로 쓸 수 있다. 메모지는 테이프로 붙은 것처럼 보인다 |
| D2 | **종이와 펜** | 점 모눈 종이 위에 손으로 그린 테두리·체크·밑줄. 아이콘과 같은 크레용 빗금과 굵은 외곽선 |
| D3 | **손글씨는 머리에, 본문은 읽기 쉽게** | 제목·카드·주석은 손글씨, Markdown 본문·코드·숫자는 Pretendard·JetBrains Mono |
| D4 | **조용한 관제판** (VISION 6) | 색은 노트 색과 상태에만. 정체·대기만 경고색. 반복하는 깜빡임 없음 |
| D5 | **터미널과 한 몸** | 같은 색 테마, 같은 노트 색, 같은 탭과 배치, 같은 크기(page/half/card) |

## 3.2 브랜드: 아이콘

[사용자 결정] 아이콘은 **파랑·빨강·노랑 메모지 세 장을 겹친 모양**이다. 크레용 빗금 채우기, 굵은 검은 외곽선, 맨 위 노랑 메모지의 말린 모서리.

- 아이콘의 문법(옅은 바탕 + 빗금 + 굵은 외곽선)이 손그림 스타일의 카드·버튼·로고에 그대로 쓰인다.
- 앱 아이콘·트레이 아이콘·창 제목줄 로고에 쓴다. 트레이(메뉴 막대)용은 단색 템플릿 이미지를 따로 만든다.
- 원본 파일 위치: `docs/overlay/assets/icon.png` (사용자가 넣는다).

## 3.3 테마: 두 축

[사용자 결정] 테마는 고를 수 있다. 축은 둘이다.

```mermaid
flowchart LR
  subgraph color["색 테마 (기존 theme 키, 터미널과 공유)"]
    c1["stickypane-dark / light"]
    c2["catppuccin-mocha / latte"]
    c3["tokyonight-night / day"]
    c4["gruvbox-dark / light"]
    c5["nord · dracula"]
  end
  subgraph style["스타일 테마 (새 style 키)"]
    s1["손그림 doodle (기본)"]
    s2["단정 neat"]
  end
  color --> screen["overlay 화면"]
  style --> screen
```

| 축 | 값 | 저장 | 바꾸는 곳 |
|---|---|---|---|
| 색 | 기존 10개 | `sticky.json` `"theme"` (기존) | 터미널 설정 패널, `stickypane theme`, overlay 설정 |
| 스타일 | `doodle`(기본) · `neat` | `sticky.json` `"style"` (신규) | overlay 설정, `stickypane init` |

[설계자 판단] 기본 스타일은 아이콘과 맞는 **손그림**이다. 터미널은 스타일 키를 무시한다.

| | 손그림 doodle | 단정 neat |
|---|---|---|
| 선 | rough.js `roughness≈1.3`, 메모지마다 ±2° 기울기 | 직선, 기울기 없음 |
| 채우기 | 옅은 바탕 + 크레용 빗금(−41°) | 단색 옅은 바탕 |
| 장식 | 테이프, 손으로 그린 밑줄·형광펜·동그라미 | 없음 |
| 제목 글꼴 | Gaegu Bold | Pretendard SemiBold |

## 3.4 색 토큰

`internal/theme`의 역할을 CSS 변수로 옮긴다. 값은 bridge가 `settings.get`으로 내려 준다. 화면은 자기 색을 갖지 않는다.

| 토큰 | 출처 | 쓰임 |
|---|---|---|
| `--base` | `Base` | 버튼 위 글자, 진한 카드 글자 |
| `--ink` | `Text` | 본문 |
| `--pencil` | `Muted` | 열 제목, 경과 시간, 보조선, 체크박스 |
| `--accent` | `Accent` | 포커스, 선택, 활성 탭 밑줄, 주 버튼 |
| `--select` | `Select` | 코드 배경, 비활성 칩 테두리 |
| `--good` / `--warn` / `--bad` / `--info` | 같은 이름 | 체크 / 정체·대기 / 오류 / 헤딩·키워드 |
| `--yellow` … `--orange` | `Notes[6]` | 노트 테두리·제목, 카드 색, 에이전트 색 |
| `--paper` | `Base`를 6% 어둡게(어두운 테마) / 50% 밝게(밝은 테마) | 창 종이 |
| `--dot` | `Base`와 `Text` 사이 12~16% | 점 모눈 |

**파생 규칙**
- 카드 바탕(wash) = 노트 색을 흰색 쪽으로 35%(어두운 테마) 또는 78%(밝은 테마). 빗금은 노트 색 그대로.
- 외곽선 = 어두운 테마는 `Base`를 55% 어둡게, 밝은 테마는 `Text`.
- **에이전트 색** = 이름을 해시해 `Notes[6]` 중 하나. 같은 이름은 어느 프로젝트에서나 같은 색. 노트의 `color` 규칙(파일 이름 해시)과 같은 방식이다.

## 3.5 글꼴

[사용자 결정] 오픈소스로 쓸 수 있는 글꼴만 쓰고, 앱에 번들한다(CSP로 외부 요청 차단).

| 역할 | 글꼴 | 라이선스 | 쓰는 곳 |
|---|---|---|---|
| 손글씨 | **Gaegu** 400/700 (JIKJI SOFT) | OFL-1.1 | 프로젝트 이름, 노트 제목, 카드, 열 제목, 배지, 주석 |
| 본문 | **Pretendard Variable** 1.3.9 | OFL-1.1 | Markdown 본문, form 선택지, 체크 항목, 칩의 설명 |
| 고정폭 | **JetBrains Mono** | OFL-1.1 | 코드, 경과 시간, 개수, 단축키 표시 |
| 고정폭 한글 | D2Coding | OFL-1.1 | 로그·코드 안의 한글 정렬이 필요할 때 fallback |

- 숫자는 `font-variant-numeric: tabular-nums`. 값이 바뀌어도 폭이 흔들리지 않는다.
- 한글 손글씨 크기는 라틴보다 1~2px 크게 보이도록 Gaegu는 본문보다 3~5px 크게 쓴다(목업 기준 제목 21px, 카드 16px, 본문 13px).
- 글꼴 라이선스 사본을 앱 번들과 `THIRD_PARTY_NOTICES.md`에 넣는다. JetBrains Mono를 수정하면 이름을 바꿔야 한다(상표).

## 3.6 창 구성

```text
┌──────────────────────────────────────────────────────────────┐
│ [로고] stickypane  ~/path            ⌥Space  [+ 끄적이기] [📌] │  제목줄 (드래그 영역)
│ (@claude 지금 카드 4m) (@codex … 28m) (@sam …)   멈춤 1       │  Glance 줄
│ 작업  노트  기록  묻기                                         │  탭 = 폴더
│ ┌─ 노트(page) ───────────────────────────────────────────┐   │
│ │ board: 열마다 작은 메모지 카드                            │   │  본문 = 그리드
│ └────────────────────────────────────────────────────────┘   │  page = 2칸
│ ┌─ 노트(half) ──────────┐ ┌─ 노트(half) ──────────┐          │  half = 1칸
│ └──────────────────────┘ └──────────────────────┘          │  card = 1칸, 작게
└──────────────────────────────────────────────────────────────┘
```

| 영역 | 규칙 |
|---|---|
| 창 | 기본 840×(화면 높이 70%), 둥근 모서리 16, 그림자. 프레임 없는 창, 제목줄이 드래그 영역 |
| 제목줄 | 로고, 프로젝트 이름(손글씨), 경로, 단축키, "+ 끄적이기", 핀 |
| Glance 줄 | 에이전트마다 이름표 하나: `@이름`(에이전트 색, 손글씨) · 지금 카드 · 경과 시간. 정체면 경고색 테두리. 누르면 그 에이전트로 필터 |
| 탭 | 터미널과 같은 폴더 탭. 활성 탭은 손으로 그은 밑줄 |
| 본문 | 2열 그리드. 노트의 `size`가 `page`면 2칸, `half`·`card`면 1칸. 순서는 터미널과 같다(고정 먼저, 파일 이름순) |
| 좁은 창 | 폭 720px 미만이면 1열, board는 2열로 접힌다 |

## 3.7 shape별 패턴

| shape | 손그림 스타일에서 |
|---|---|
| 노트(모든 shape 공통) | 노트 색 손그림 테두리, 위에 테이프 한 조각, 손글씨 제목, 오른쪽 위에 요약(`3/6`, `카드 6장`) |
| board | 열 제목은 손글씨 + 개수. 카드는 작은 포스트잇: 담당자 색 wash + 빗금 + 굵은 외곽선, 아래에 `@담당자`와 경과 시간. 정체 카드는 손으로 그린 경고색 동그라미 |
| checklist | 손그림 체크박스, 체크는 펜으로 그은 ✓, 완료 항목은 손으로 그은 취소선과 `--pencil` 글자 |
| form | 질문은 손글씨, 선택지는 손그림 라디오·체크, 답하기 버튼은 accent wash + 빗금. 미제출이면 "답 대기", 제출하면 "답했어요 ✓" |
| note(Markdown) | 본문은 Pretendard, 헤딩은 손글씨, 강조(`==mark==` 또는 `**굵게**`의 첫 출현)는 형광펜 낙서 대신 굵게만. 코드 블록은 Shiki, 다이어그램은 Mermaid(`handDrawn` look이 있으면 손그림에서 사용 [미검증]) |
| chart | 막대·추세·달력을 rough.js로(손그림) 또는 SVG 직선으로(단정) |
| logview | 고정폭, 끝을 따라감. 새 줄은 위로 밀려 들어옴 |
| script / api | 코드 블록 + 손그림 "▶ 실행" 버튼. 누르면 확인 → 실행 → 아래에 로그 |
| chat | 말풍선 없이 `@이름 시각 내용` 줄. 이름은 에이전트 색 손글씨 |
| html | 손그림 테두리 안의 샌드박스 iframe. 머리에 "HTML · 보기 전용" 배지 |

## 3.8 접근성

- 대비: 본문 글자는 `--ink` on `--paper`. 카드 글자는 wash 위 진한 색. 테마마다 4.5:1을 넘는지 테스트한다(밝은 테마의 노란 카드가 가장 위험).
- 색만으로 상태를 말하지 않는다: 정체는 색 + 동그라미 + 경과 시간 숫자, 체크는 색 + ✓ + 취소선.
- 키보드: 탭 이동(`Tab`), 노트 사이(`←→↑↓`), 체크(`Space`), 열기(`Enter` → `$EDITOR`), 끄적이기(`N`), 숨기기(`Esc`). 터미널의 키와 겹치게 고른다.
- 손글씨가 읽기 어려운 사람을 위해 단정 스타일이 있다.
- `prefers-reduced-motion`은 [04 §4.6](04-motion.md#46-동작-줄이기).

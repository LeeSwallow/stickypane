# 폴더와 노트의 모양

`.sticky/`가 어떻게 보드가 되는지입니다. 모양마다의 파일 형식과 예시는 영문
[shapes.md](../shapes.md)에 있고, 프로그램에서는 `stickypane help <모양>`으로 봅니다.
[README로 돌아가기](../../README.ko.md)

## 폴더가 곧 보드

`.sticky/`의 파일 하나가 노트 하나입니다. 확장자가 종류를 정합니다.

| 파일 | 무엇 |
| --- | --- |
| `*.md` | 노트. 머리말 `type`으로 `board`(칸반), `checklist`, `chart`, `chat`, `form`, `log` |
| `*.log` `*.txt` `*.out` | 로그. 그대로 보여 주고 자라는 대로 따라감 |
| `*.sh` `*.ps1` | 스크립트. 실행 버튼이 달림 (매번 y/n 확인 후 프로젝트 폴더에서 실행) |
| `*.html` `*.htm` | 웹 페이지(보기만). 터미널에는 글만 보여 줌 |
| 폴더 | 탭. 화면 하나를 따로 가지며 그 안의 파일이 노트 |
| 탭 안의 폴더 | 책. 파일 하나가 페이지 하나, `,` `.`으로 넘김 |

마크다운 노트 안의 ```` ```mermaid ```` 블록은 그림으로 그려집니다(순서도, 시퀀스,
ER). `stickypane show README.md`처럼 프로젝트의 어떤 파일이든 복사 없이 보드에
올릴 수 있습니다(심볼릭 링크).

## 폼

에이전트가 질문을 쓰고, 당신이 보드에서 답하면 답이 같은 파일에 남습니다.
`- ( )`는 하나만 고르는 선택지, `- [ ]`는 여럿 고르는 선택지, `> `는 채울 줄,
`[ 배포 ] [ 취소 ]`는 버튼입니다. 에이전트는 `stickypane wait`로 버튼이 눌리기를
기다립니다.

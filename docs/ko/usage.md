# 보드 쓰기

키, 마우스, 편집기 이야기입니다. 영문 [usage.md](../usage.md)가 원본이고 더
자세합니다(인덱스, 노트 옮기기, `stickypane watch`, 편집이 쓰이는 방식).
[README로 돌아가기](../../README.ko.md)

명령마다 도움말이 프로그램 안에 있습니다. `stickypane help <명령>`은 명령 하나를
예시와 함께, `stickypane help --all`은 모든 명령과 옵션을 한 페이지에 보여 줍니다.

## 키

| 노트 | | 열린 칸반·체크리스트 | |
| --- | --- | --- | --- |
| `tab` `shift+tab` | 다음, 이전 노트 | `h` `l` | 칸 바꾸기 |
| `enter` | 열기, 그다음 크게 | `j` `k` | 카드·항목 바꾸기 |
| `o` | 열기 / 닫기 | `H` `L` | 카드를 옆 칸으로 |
| `+` `-` | 넓게 / 좁게 (화면의 1/4 1/3 1/2 2/3 3/4 1) | `J` `K` | 카드 순서 |
| `shift+up` `shift+down` | 한 줄 높게 / 낮게 (`pgup` `pgdn`은 다섯 줄) | | |
| `0` | 내용만큼 높이 | | |
| `{` `}` | 앞으로 / 뒤로 옮기기 | `space` | 체크 |
| `m` | 폴더로 옮기기 | `n` | 새 카드·항목 |
| `e` `E` | 여기서 편집(vi 방식), `$EDITOR`로 | **폼** | |
| `x` `D` `u` | 보관, 삭제(휴지통), 되돌리기 | `enter` `space` | 고르기, 입력, 누르기 |
| `T` | 다음 테마 | **크게 본 노트** | |
| `[` `]` | 이전 / 다음 화면 | `esc` | 뒤로 |
| `i` `/` | 인덱스 | `S` | 설정 |
| `?` `q` | 도움말, 종료 | | |

## 마우스

제목 클릭(열기·포커스·닫기), 노트 클릭(포커스, 항목 체크), 더블 클릭(크게),
휠(그 노트 스크롤), 오른쪽 끝 끌기(너비, 가까운 비율로), 아래 끝 끌기(높이),
아래 끝 더블 클릭(내용만큼 높이). tmux에서는 `set -g mouse on`이 필요합니다.

## 지우기와 옮기기

보드에서 하는 어떤 일도 파일을 없애지 않습니다. `D`는 묻고 나서
`.sticky/.trash/`로, `x`는 묻지 않고 `.sticky/archive/`로 옮기며, `u`가 마지막
것을 되돌립니다.

```sh
stickypane mv plan deploy/       # deploy 탭으로
stickypane rm plan               # .sticky/.trash/로
stickypane restore plan          # 되돌리기
```

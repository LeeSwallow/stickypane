# 보드 쓰기

키, 마우스, 편집기 이야기입니다. 영문 [usage.md](../usage.md)가 원본이고 더
자세합니다(인덱스, 노트 옮기기, `stickypane watch`, 편집이 쓰이는 방식).
[README로 돌아가기](../../README.ko.md)

명령마다 도움말이 프로그램 안에 있습니다. `stickypane help <명령>`은 명령 하나를
예시와 함께, `stickypane help --all`은 모든 명령과 옵션을 한 페이지에 보여 줍니다.

## 키

보드의 키는 vim에 있는 것이면 vim 그대로입니다.

| 노트 | | 열린 칸반·체크리스트 | |
| --- | --- | --- | --- |
| `h` `j` `k` `l` | 그쪽 노트로 | `←` `→` (크게 보면 `h` `l`) | 칸 바꾸기 |
| `gg` `G` | 첫 노트, 끝 노트 | `↑` `↓` (크게 보면 `k` `j`) | 카드·항목 바꾸기 |
| `tab` `shift+tab` | 다음, 이전 노트 | `H` `L`, 크게 볼 때 | 카드를 옆 칸으로 |
| `enter` | 열기, 그다음 크게 | `J` `K`, 크게 볼 때 | 카드 순서 |
| `o` | 열기 / 닫기 | `space` | 체크 |
| `>` `<` (`+` `-`) | 한 칸 넓게 / 좁게 | `n` | 새 카드·항목 |
| `shift+up` `shift+down` | 한 줄 높게 / 낮게 (`pgup` `pgdn`은 다섯 줄) | **폼** | |
| `0` | 내용만큼 높이 | `↑` `↓` (크게 보면 `k` `j`) | 항목 바꾸기 |
| `ctrl+e` `ctrl+y` (`↓` `↑`) | 한 줄 스크롤 | `enter` `space` | 고르기, 입력, 누르기 |
| `ctrl+d` `ctrl+u` | 반 페이지 스크롤 | | |
| `pgdn` `pgup` | 한 페이지 스크롤 | **크게 본 노트** | |
| `H` `L` | 앞으로 / 뒤로 옮기기 | `esc` | 뒤로 |
| `K` `J` | 한 줄 위 / 아래로 | `j` `k` `g` `G` | 스크롤 |
| `m` | 폴더로 옮기기 | | |
| `e` `E` | 여기서 편집(vi 방식), `$EDITOR`로 | | |
| `x` `dd` `u` | 보관, 삭제(휴지통), 되돌리기 | | |
| `yy` | 노트 경로 복사 | | |
| `T` | 다음 테마 | | |
| `[` `]` | 이전 / 다음 화면 | | |
| `1`–`9` `gt` `gT` | 탭 바꾸기 | | |
| `i` `/` | 인덱스 | `S` | 설정 |
| `f` | 연결된 노트 | | |
| `?` `q` | 도움말, 종료 | | |

보드에서 `h` `j` `k` `l`은 언제나 화면에 보이는 대로 옆 노트로 갑니다. 마지막 줄에서
아래로 가면 다음 화면으로, 닫힌 노트에서는 제목 줄 순서대로 갑니다. `H` `J` `K` `L`과
`gg` `G`도 보드의 키입니다. 포커스된 열린 노트는 나머지 자기 키를 그 자리에서 받으니,
항목 체크, 카드 추가, 화살표로 커서 옮기기는 크게 보지 않아도 됩니다. 크게 보면(`enter`,
`enter`를 스스로 쓰는 폼 같은 노트는 `z`) 노트가 자기 키를 모두 받습니다. 칸반은
`h` `j` `k` `l`로 커서를, `H` `J` `K` `L`로 카드를 옮깁니다.

`yy`는 포커스된 노트의 파일 경로를 프로젝트 기준으로 복사합니다(`.sticky/plan.md`,
링크한 노트면 프로젝트의 그 파일). 터미널의 OSC 52로 복사하니 ssh에서도 되고, tmux에서는
`set -g set-clipboard on`이 필요합니다.

보드는 기본 세 칸입니다(`columns`, `1`–`4`). 크기를 정하지 않은 노트는 한 칸을 차지하고,
한 줄의 노트는 너비를 똑같이 나눕니다. 크기를 정한 노트는 그 비율만큼 칸을 차지합니다(세 칸에서
`1/2`·`2/3`은 두 칸).

키 앞의 숫자는 횟수입니다: `3J`는 노트를 세 줄 아래로 옮깁니다. 숫자 하나만 누르고 더 누르지
않으면 그 탭으로 갑니다. 두벌식 한글 입력이 켜져 있어도 보드는 `ㅓ`를 `j`로, 다른 자모도
그 자리의 영문 키로 읽습니다.

`:`는 vim처럼 아래 줄에 명령줄을 엽니다. 명령을 치고 `enter`로 실행, `esc`로 취소합니다.
`↑` `↓`는 이번에 실행한 명령을 다시 불러오고, `tab`은 명령 이름, 설정, 테마, 노트 이름을
채웁니다. 다른 명령과 겹치지 않으면 앞부분만 쳐도 됩니다: `:col 3`, `:th nord`.
명령 이름은 영어 그대로입니다.

| 명령 | |
| --- | --- |
| `:q` | 종료 (`:q!`, `:wq`도) |
| `:w` | 저장할 것 없음: 보드는 바로 저장합니다 |
| `:set [설정 [값]]` | 설정 목록, 값 보기, 바꾸기 (`:set stale=1h`) |
| `:theme` / `:col` / `:lang [값]` | 그 설정 보기·바꾸기 |
| `:e <노트>` | 이름이나 제목으로 노트를 크게 보기, 다른 탭에 있어도; 이름이 없으면 인덱스 |
| `:new [모양] [제목]` | 노트 추가: `:new idea`, `:new checklist Release`; 혼자 쓰면 모양 고르기 |
| `:jot [글]` | 한 줄 메모 |
| `:tab <번호\|이름>` | 탭으로 가기 |
| `:archive` / `:delete` / `:undo` | 이름으로 하는 `x`, `dd`, `u` (`:restore`도 `:undo`) |
| `:3` | 탭의 세 번째 노트로 |
| `:keys` / `:help [명령]` | 키 보기, 명령 설명 |

명령은 그 키나 설정 창이 하는 일을 같은 코드로 합니다. `:`는 `command-line` 동작이라
`stickypane keys set command-line ";"`로 옮길 수 있습니다. 명령줄에서는 자모가 자모 그대로 쳐집니다.

위 표는 처음 그대로의 키입니다. 보드의 키는 저마다 이름 있는 동작(`note-archive`,
`jot`)에 묶여 있고, `stickypane keys`가 지금 쓰는 키와 함께 보여 줍니다. 바꾸는 법은
[configuration.md](configuration.md#키)에 있습니다.

## 마우스

제목 클릭(열기·포커스·닫기), 노트 클릭(포커스, 항목 체크), 더블 클릭(크게),
휠(그 노트 스크롤), 오른쪽 끝 끌기(너비, 가까운 칸으로), 아래 끝 끌기(높이),
아래 끝 더블 클릭(내용만큼 높이). tmux에서는 `set -g mouse on`이 필요합니다.

## 지우기와 옮기기

보드에서 하는 어떤 일도 파일을 없애지 않습니다. `dd`는 묻고 나서
`.sticky/.trash/`로, `x`는 묻지 않고 `.sticky/archive/`로 옮기며, `u`가 마지막
것을 되돌립니다.

```sh
stickypane mv plan deploy/       # deploy 탭으로
stickypane rm plan               # .sticky/.trash/로
stickypane restore plan          # 되돌리기
```

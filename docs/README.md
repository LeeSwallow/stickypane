# Docs

Where each part of stickypane is written down. The [README](../README.md)
is the short version of the first five.

- [install.md](install.md): every way to install, update and remove it.
- [usage.md](usage.md): the keys, the mouse, the editor and the command line.
- [shapes.md](shapes.md): each shape of note, its file format and an example.
- [agents.md](agents.md): what an agent runs, with the plugin, MCP or neither.
- [configuration.md](configuration.md): themes, language, settings and what is kept on this machine.
- [architecture.md](architecture.md): the packages, their layers, how a note is read and written, the tests.
- [plugin.md](plugin.md): the Claude Code and Codex plugin in `plugin/`.
- [translating.md](translating.md): adding a language, one JSON file.
- [desktop/](desktop/README.md): the desktop app's design documents and its decision records ([adr/](desktop/adr/)).
- [ko/](ko/): the user docs in Korean.
- [history/](history/README.md): dated plans and specs, kept as they were written.

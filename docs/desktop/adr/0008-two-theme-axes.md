# ADR-0008. 테마는 색과 스타일 두 축이고, 기본 스타일은 손그림이다

| 항목 | 값 |
|---|---|
| 상태 | Proposed |
| 날짜 | 2026-10-28 |
| 관련 요구 | R-20, R-21, R-23, R-24 |

## 맥락

사용자는 doodle(Excalidraw 같은 손그림) 방향을 좋아하지만 테마를 고를 수 있어야 한다고 했다(R-21, R-23). 터미널에는 이미 색 테마 10개가 `sticky.json`의 `theme` 키로 있다.

## 결정

색 테마는 기존 `theme` 키를 터미널과 공유한다. 스타일 테마는 새 `style` 키(`doodle` | `neat`)로 앱만 읽는다. 기본은 `doodle`([설계자 판단] R-24).

## 결과

- 한쪽에서 색 테마를 바꾸면 양쪽이 바뀐다.
- 새 색 테마는 `internal/core/theme`에 한 번 추가하면 양쪽에 생긴다.
- 단정 스타일은 손글씨가 불편한 사람을 위한 접근성 선택지이기도 하다.

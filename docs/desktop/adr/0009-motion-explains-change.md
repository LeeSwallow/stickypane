# ADR-0009. 움직임은 변화를 설명할 때만 쓴다

| 항목 | 값 |
|---|---|
| 상태 | Proposed |
| 날짜 | 2026-10-28 |
| 관련 요구 | R-15, R-20 |

## 맥락

여러 에이전트가 동시에 쓰면 화면이 자주 바뀐다. 움직임이 없으면 무엇이 바뀌었는지 모르고, 지나치면 VISION 6을 어긴다.

## 결정

Motion은 bridge가 보내는 사건(`card.moved`, `item.ticked` 등)에만 반응하고, 상태가 바뀌는 순간 한 번 움직인다. 반복 애니메이션은 없다. 많으면 묶고 줄인다. `prefers-reduced-motion`이면 fade만 남긴다([04](../04-motion.md)).

## 결과

- 사건 이름이 화면과 `stickypane watch`에서 같다.
- Motion 토큰은 세 가지 시간과 세 가지 곡선뿐이다.

# ADR-0007. 창은 전역 단축키로 토글하고, 핀으로 고정한다

| 항목 | 값 |
|---|---|
| 상태 | Proposed |
| 날짜 | 2026-10-28 |
| 관련 요구 | R-09 |

## 맥락

앱은 잠깐 보고 손을 떼는 창이다. 여러 에이전트를 지켜볼 때는 계속 띄워 두고 싶다. 사용자는 둘 중 어느 쪽을 더 쓸지 모르겠다고 했다(R-09).

## 결정

[설계자 판단] 둘 다 둔다. 기본은 전역 단축키(`⌥ Space`, 바꿀 수 있음)로 부르고, 포커스를 잃으면 숨긴다. 핀을 켜면 always-on-top으로 남는다. 늘 반투명하게 겹쳐 있는 모드는 두지 않는다(VISION 6).

## 결과

- 단축키는 마지막으로 쓴 프로젝트 창을 토글한다.
- 창 위치·크기·핀 상태는 앱 설정에 둔다(노트가 아니다).

# ADR-0017. 앱은 자유 캔버스와 떼어낸 노트를 두고, 위치는 이 컴퓨터에만 둔다

| 항목 | 값 |
|---|---|
| 상태 | Accepted |
| 날짜 | 2026-10-28 |
| 관련 요구 | R-39, R-40 |

## 맥락

사용자는 앱에서 노트를 StickyModal처럼 여기저기 붙이길 원한다. 터미널의 타일 배치와는 별개로 다루되, 노트 내용은 공유되어야 한다(R-39, R-40). 지금의 배치는 터미널과 같은 2열 그리드다.

## 결정

앱 보드의 기본 배치를 **자유 캔버스**로 하고(그리드는 토글로 남긴다), 노트를 **떼어내** 독립된 작은 창으로 화면 어디에나 붙일 수 있게 한다. 위치·크기·기울기·겹침·떼어냄 상태는 `~/.stickypane/overlay.json`의 프로젝트별 항목에만 쓴다. 노트 파일과 `sticky.json`은 이 배치 때문에 바뀌지 않는다.

## 결과

- VISION 1(폴더가 제품)은 그대로다: 내용은 파일, 머신별 보기 상태는 앱 설정.
- 같은 노트가 터미널과 앱에서 다른 자리·크기에 있을 수 있다. 의도된 것이다.
- 다른 컴퓨터나 앱 재설치에서는 배치가 그리드 자리에서 다시 시작한다.
- 떼어낸 노트마다 Wails 창이 하나 생긴다. 창 수가 많아지면 메모리를 쓴다(노트 창은 같은 프로젝트 bridge를 공유한다).
